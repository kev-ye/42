Ex00 : Markdown Cheatsheet.

Headers

        # H1
        ## H2
        ### H3
        #### H4
        ##### H5
        ###### H6

Emphasis

Syntax Result
*italic* or _italic_ italic
**bold** or __bold__ bold
***bold italic*** bold italic
~~strikethrough~~ strikethrough

Lists

Unordered List

        - Item 1
        - Item 2
        - Subitem 2.1
        - Subitem 2.2
        - Item 3

Or use * or + instead of -

Ordered List

        1. First item
        2. Second item
        3. Third item

Links

        [Link text](https://www.example.com)
        [Link with title](https://www.example.com "Title")
        <https://www.example.com>

Images

        ![Alt text](image.jpg)
        ![Alt text](image.jpg "Image title")

Code

Inline Code

Use `code` in your text

Code Blocks

        ```python
        def hello():
            print("Hello, World!")```

Or indent with 4 spaces:

        def hello():
            print("Hello, World!")

Blockquotes

        > This is a blockquote
        > 
        > Multiple lines

Nested blockquotes:

> Level 1
        > > Level 2
        > > > Level 3

Horizontal Rule

        ---
        ***
        ___

Tables

        | Header 1 | Header 2 | Header 3 |
        |----------|----------|----------|
        | Cell 1   | Cell 2   | Cell 3   |
        | Cell 4   | Cell 5   | Cell 6   |

Alignment:

        | Left | Center | Right |
        |:-----|:------:|------:|
        | L1   |   C1   |    R1 |
        | L2   |   C2   |    R2 |

Task Lists

        - [x] Completed task
        - [ ] Incomplete task
        - [ ] Another task

Escaping Characters

Use backslash \ to escape special characters:

        \* Not italic \*
        \# Not a header
        \[Not a link\](url)

HTML in Markdown

You can use HTML tags directly in Markdown:

        <div style="color: red;">
        This is red text
        </div>

Footnotes

        Here's a sentence with a footnote[^1].

        [^1]: This is the footnote.

Definition Lists

        Term 1
        : Definition 1

        Term 2
        : Definition 2a
        : Definition 2b
