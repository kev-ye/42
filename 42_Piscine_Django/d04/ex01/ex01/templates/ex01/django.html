Ex01 : Django, framework web.

What is Django?

Django is a high-level Python web framework that encourages rapid development and clean, pragmatic design.

History

Django was created in 2003 by Adrian Holovaty and Simon Willison while working at the Lawrence Journal-World newspaper.

It was released publicly under a BSD license in July 2005.

The framework was named after guitarist Django Reinhardt.
