Ex01 : Moteur de template.

Django Template Engine

Django's template engine provides tags and filters to define the presentation layer.

Blocks

Blocks allow child templates to override sections of parent templates.

{% templatetag openblock %} block content {% templatetag closeblock %}...{% templatetag openblock %} endblock {% templatetag closeblock %}

For Loops

Iterate over items in a list:

{% templatetag openblock %} for item in list {% templatetag closeblock %}...{% templatetag openblock %} endfor {% templatetag closeblock %}

If Statements

Conditional display of content:

{% templatetag openblock %} if condition {% templatetag closeblock %}...{% templatetag openblock %} endif {% templatetag closeblock %}

Variables

Display variables passed from view context:

{% templatetag openvariable %} variable_name {% templatetag closevariable %}
