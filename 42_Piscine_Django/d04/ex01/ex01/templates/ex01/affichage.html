Ex01 : Processus d'affichage d'une page statique.

Request to Response Process

  1. Client sends HTTP request to Django server
  2. URL dispatcher matches the URL pattern in urls.py
  3. Corresponding view function is called
  4. View renders the template with context data
  5. Template engine processes the template
  6. HTML response is sent back to client
