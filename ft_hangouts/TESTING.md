# ft_hangouts 测试指南

## 快速开始

### 1. 打开项目
```bash
cd ft_hangouts
open ft_hangouts.xcodeproj
```

### 2. 运行应用
- 在Xcode中选择iPhone模拟器（建议：iPhone 15 Pro）
- 点击运行按钮 ▶️ 或按 `Cmd + R`

## 测试场景

### 场景1：用户注册和登录
1. ✅ 应用启动后显示登录界面
2. ✅ 输入任意手机号（例如：+1234567890）
3. ✅ 点击"登录"按钮
4. ✅ 验证：进入主界面，显示三个标签（联系人、消息、设置）

### 场景2：创建联系人
1. ✅ 点击"联系人"标签
2. ✅ 点击右上角"+"按钮
3. ✅ 填写信息：
   - 姓名：张三
   - 电话：+1234567891
   - 邮箱：zhangsan@example.com
   - 地址：北京市朝阳区
   - 生日：1990-01-01
   - 备注：好朋友
4. ✅ （可选）点击"选择照片"添加照片
5. ✅ 点击"保存"
6. ✅ 验证：联系人列表显示新联系人

### 场景3：编辑联系人
1. ✅ 点击联系人进入详情页
2. ✅ 点击右上角"编辑"按钮
3. ✅ 修改信息（例如更改邮箱）
4. ✅ 点击"完成"
5. ✅ 验证：信息已更新

### 场景4：删除联系人
1. ✅ 在联系人列表左滑
2. ✅ 点击"删除"
3. ✅ 验证：联系人已从列表移除

### 场景5：发送消息（需要两个用户）
**准备工作**：创建第二个用户
1. 进入"设置"标签
2. 点击"退出登录"
3. 用另一个号码登录（例如：+1234567891）

**发送消息**：
1. ✅ 切换回第一个用户（+1234567890）
2. ✅ 进入"消息"标签
3. ✅ 点击右上角"新消息"按钮
4. ✅ 输入接收者号码：+1234567891
5. ✅ 输入消息内容："你好！"
6. ✅ 点击"发送"
7. ✅ 验证：消息显示在对话界面

**查看消息**：
1. ✅ 切换到第二个用户（设置 → 切换用户）
2. ✅ 进入"消息"标签
3. ✅ 验证：看到来自第一个用户的消息

### 场景6：联系人发消息
1. ✅ 创建一个联系人，电话号码为已注册用户
2. ✅ 点击联系人进入详情
3. ✅ 点击"发送消息"
4. ✅ 输入消息并发送
5. ✅ 验证：消息成功发送

### 场景7：拨打电话
1. ✅ 进入联系人详情
2. ✅ 点击"拨打电话"
3. ✅ 验证：弹出拨号提示（模拟器会显示无法拨号）

### 场景8：更改标题颜色
1. ✅ 进入"设置"标签
2. ✅ 点击"标题颜色"
3. ✅ 选择一个颜色（例如：红色）
4. ✅ 点击"完成"
5. ✅ 验证：所有标签页的标题颜色已更改

### 场景9：切换语言
1. ✅ 进入"设置"标签
2. ✅ 在"语言"选择器中选择"中文"或"English"
3. ✅ 验证：界面文字已切换到对应语言
4. ✅ 注意：部分界面可能需要重启应用才能完全更新

### 场景10：后台时间显示
1. ✅ 在应用首页
2. ✅ 按 `Cmd + Shift + H`（模拟器返回主屏幕）
3. ✅ 等待几秒
4. ✅ 重新打开应用
5. ✅ 验证：底部显示Toast提示，显示应用进入后台的时间

### 场景11：横竖屏切换
1. ✅ 在任意界面
2. ✅ 旋转设备或模拟器（`Cmd + 左/右箭头`）
3. ✅ 验证：界面正确适配横屏和竖屏

### 场景12：切换用户
1. ✅ 进入"设置"标签
2. ✅ 点击"切换用户"
3. ✅ 从列表中选择其他用户
4. ✅ 验证：切换到新用户，看到该用户的联系人和消息

## 已知限制

1. **真实短信**：应用无法发送真实SMS，只能在应用内模拟
2. **通话功能**：模拟器无法真实拨号，真机可以
3. **语言切换**：某些系统界面需要重启应用才能更新
4. **照片权限**：首次使用需要授权相册访问

## 常见问题

**Q: 为什么无法向某个号码发送消息？**  
A: 接收者必须先在应用中注册（即用该号码登录过一次）

**Q: 如何测试多用户？**  
A: 在设置中退出登录，然后用不同号码登录创建新用户

**Q: 数据存储在哪里？**  
A: SQLite数据库存储在应用沙盒的Documents目录

**Q: 为什么语言没有完全切换？**  
A: 某些系统组件需要重启应用，建议实现语言切换后重启应用

**Q: 如何添加42 Logo？**  
A: 在Xcode中打开Assets.xcassets，将1024x1024的logo拖入AppIcon
